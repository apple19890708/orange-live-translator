# 持續校準計畫書

> 建立：2026-11-23　｜　目標：讓即時翻譯「越用越準」，而且不靠使用者一直開直播、不重複做工、不學到錯的東西。
> 相關：[README.md](README.md)（調校流程）、[experiments.md](experiments.md)、[issues.md](issues.md)、[../CLAUDE.md](../CLAUDE.md)（規則）

## 1. 現況與問題

- 辨識錯誤率 6.6%（白玖ウタノ公告參考稿），翻譯靠本機 Sakura 7B／qwen3:8b。
- 一般參數已調到接近極限（35 個實驗，多數無效）；**剩下的錯誤主要是「這個圈子的詞」**：人名、活動、直播用語、口語（台北公演、整理券、齟齬、一人一枚、アルバム→專輯）。
- 目前的評分只有**一段 7 分鐘的公告**，調出來的設定可能只對這段有效；**翻譯品質沒有客觀分數**，只靠人工閱讀判斷。

## 2. 目標

1. 建立**多元、有標準答案的基準**：辨識（日文逐字稿）與翻譯（人工中文字幕）都能自動評分。
2. 建立**自動校準循環**：從大量影片中找出常聽錯／翻錯的詞，安全地累積進詞彙表。
3. 使用者的負擔只剩：偶爾回報、每週看一份週報。

## 3. 資料來源

| 來源 | 內容 | 用途 | 狀態 |
|---|---|---|---|
| A. 白玖ウタノ公告段落 | 7 分 40 秒，人工校對日文逐字稿 | 辨識 CER 基準 | ✅ `benchmark/utano_announce*` |
| B. **鈐 Mae 頻道的翻譯剪輯** | 159 部，燒在畫面上的人工中文字幕（主要是白玖ウタノ，也有其他 VTuber） | **翻譯基準**（音訊→我們的中文 vs 人工中文） | ✅ 首批 4 部（214 句）；「請開CC」的影片只有少量補充字幕，不能當完整參考 |
| C. 使用者回報的片段 | 從 `logs/*.pcm` 剪下 | 回歸案例 | ✅ `cases/`（5 個） |
| D. 主播的直播存檔 | 白玖ウタノ等主播的 2～4 小時存檔 | 自動找錯（沒有標準答案，用離線精聽比對） | 📋 規劃中 |
| E. 使用者平常看直播的錄音 | 自動錄在 `logs/` | 同 D | ✅ 已在錄 |

**為什麼不用新聞**：Whisper 本來就擅長標準日文；用 3.5 萬小時電視節目訓練的 ReazonSpeech 在直播上錯誤率反而 27%。我們缺的是直播口語與圈內用語，不是標準發音（見 experiments.md E08）。

### B 的處理方式（燒在畫面上的字幕）

1. 下載影片（720p）與音訊。
2. `tools/extract_burned_subs.py`：每 0.2 秒偵測畫面下方的字幕，記下每句出現／消失的時間，EasyOCR 產生草稿。
3. 本機 OCR 對這種描邊字體錯字太多（每句都有），所以**由 Claude 看校對拼圖逐句校對**，存成 `benchmark/mae/<影片ID>.ref.json`。每部影片只需做一次。
4. 音訊轉成 `benchmark/mae/<影片ID>.pcm`。

## 4. 評分工具

| 工具 | 量什麼 | 基準 |
|---|---|---|
| `scripts/eval_asr.py` | 辨識 CER、定稿延遲 | A |
| `eval_translation.py` | 翻譯 chrF（和人工字幕比較，0～100） | B |
| `run_cases.py` | 回歸案例（必須／不能出現的字） | C |

**任何改動都要三個一起跑**：辨識沒變差、翻譯沒變差、回歸案例沒有退步，才算有效。

## 5. 自動校準循環（直播存檔 D／使用者錄音 E）

```
每晚自動執行（Windows 排程，電腦閒置時）
 1. 取一段還沒處理的音訊（存檔或使用者錄音）
 2. 即時模式跑一次（＝使用者看直播時會看到的字幕）
 3. 離線精聽跑一次（30 秒視窗、前後文完整，較準）
 4. 逐句比對，找出「即時 ≠ 離線」的詞 → 候選修正
 5. 防呆篩選（第 6 節）
 6. 通過的加進主播詞彙表 → 跑三個評分工具 → 沒退步才保留，否則自動撤銷
 7. 拿不準的放進「待確認清單」
 8. 寫進 experiments.md 與週報
```

## 6. 防呆規則（避免學到錯的東西）

1. **重複出現才算數**：同一組「即時寫法 → 離線寫法」在 3 段以上不同音訊出現。
2. **離線也會錯**（例：整理券→生理券）：候選要通過常識檢查（不是罕見字、不在禁用清單、和已知詞彙不衝突）。
3. **加入後必須量測**：三個評分工具任一退步就撤銷。
4. **影響大的修正一律人工確認**：例如會改變地名、人名、數字的修正。
5. **全部留紀錄**：加了什麼、為什麼、量測結果，錯了可以追查與撤銷。
6. **詞彙表分層**：通用直播用語（所有主播共用）／主播專屬（看誰的直播套用誰的），避免 A 主播的詞干擾 B 主播。

## 7. 誠實的限制

- 兩種模式都聽錯的詞抓不到（例：齟齬），要靠使用者回報或基準 B。
- 改善集中在「圈內用語」；一般聽寫能力的上限是模型本身。
- 人工字幕是意譯，chrF 分數本身偏低，只能做設定之間的相對比較。
- 本機 OCR 不可靠，基準 B 每部影片需要 Claude 校對一次。

## 9. 使用者的負擔

- 平常：照常看直播。
- 每週：看週報、勾選待確認清單（幾分鐘）。
- 看到翻錯：告訴 Claude 大概時間點 → 變成回歸案例。
